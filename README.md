# 3D Kinematics Simulation
**Physics Honors Project | San Diego Mesa College** [cite: 45, 66]

## Overview
This project simulates and visualizes projectile motion in a 3D environment. [cite_start]It was developed to bridge theoretical physics with computational modeling.

## Technical Highlights
* **Vector Math:** Utilizes **NumPy** for high-performance array processing and 3D vector operations.
* **Visualization:** Generates 3D plots using **Matplotlib** to validate physics models against simulated results.
* **Optimization:** Engineered to handle acceleration and velocity vectors in real-time.

## Tools Used
* Python
* NumPy
* Matplotlib
